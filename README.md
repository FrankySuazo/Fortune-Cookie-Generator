# 🥠 Fortune Cookie Generator

A beginner-friendly Python exercise that generates random fortune cookie messages using functions, lists, and the `random` module.

## Features
- Randomly selects from 8 fortune cookie messages.
- Uses `random.randint()` to generate a random list index.
- Demonstrates Python functions and local variables.
- Uses list indexing instead of multiple `if/elif/else` statements.

## Technologies
- Python 3
- Python `random` module

## How to Run

1. Download or clone the repository.
2. Open a terminal in the project directory.
3. Run:

```bash
python fortune_cookie.py
```

## Example Output

```text
Don't just think. Act!
All things are difficult before they are easy.
Your heart will skip a beat.
```

*Results vary each time the program runs.*

- Defining and calling functions
- Working with Python lists

- Generating random integers
